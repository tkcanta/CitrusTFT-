# 文書運用

現行仕様は索引のcurrent文書を正本とする。公開URL、機能、保存形式、外部通信、検証・配信手順が変わったら、同じ変更で関連正本を更新し、ownerと最終確認日を見直す。既存ルート文書の管理情報は索引で保持する。

状態はcurrent（現行）、draft（検討中）、deprecated（移行中）、archived（履歴）、unknown（未確定）。置換時は旧資料へ置換先・日付・理由を残し、必要になった時点で `docs/history/` へ移す。履歴は通常読まない。

長期的な互換性・安全性・運用上の判断だけ `docs/decisions/` に記録し、状況・決定・代替案・結果・再検討条件・正本へのリンクを記載する。空の履歴や判断テンプレートは作らない。
